# pc98-image-tools

PC-98向け画像フォーマットを扱うための Python ツール集です。

現在は主に MAKI02(MAG) 形式を対象とした変換・解析ツールを収録しています。

本プロジェクトは、PC-98向けアドベンチャーゲームエンジン「ADV98」の開発過程で作成したツールを独立させたものです。

## このプロジェクトについて

ADV98 の開発中、

* MAGファイルの解析
* MAG → PNG変換
* PNG → MAG変換
* パレット情報の調査

を行う必要があり、その過程で作成したツールをまとめています。

また、

**「AIでどこまでレトロPC向け開発ができるのか」**

という実験も兼ねて開発を続けています。

## 収録ツール

### 001.mag_to_png.py

MAKI02(MAG) 画像を PNG へ変換します。

```bash
python 001.mag_to_png.py input.MAG
```

### 002.png_to_mag.py

PNG 画像を MAKI02(MAG) 画像へ変換します。

BMP等の画像形式も入力できる場合がありますが、動作確認はPNG画像で行っています。

```bash
python 002.png_to_mag.py input.png output.MAG
```

### 003.mag_palette_dump.py

MAGファイルに保存されている16色パレットを抽出します。

出力:

* palette.txt
* palette.png

```bash
python 003.mag_palette_dump.py input.MAG
```

## 対応形式

本ツール群は、主に **PC-98で利用されていたMAKI02形式の16色MAG画像を対象** としています。

動作確認済み:

* 640×400
* 640×800 などの縦長画像

非対応:

* 256色MAG画像
* 確認できていない機種依存MAG形式

## PNG → MAG変換の注意

本ツールは16色のMAKI02(MAG)画像を生成します。

入力画像がパレット画像（Pモード／インデックスカラー）の場合は、パレット情報を保持したままMAGへ変換されます。

入力画像がRGB/RGBA画像の場合は、変換時に16色へ減色してからMAGへ変換されます。

実際の色数が16色以下の場合は元画像に近い結果になることがありますが、完全に一致することは保証されません。

また、入力画像の色数が16色を超える場合は、変換後の画像が元画像と異なる場合があります。

意図した色を維持したい場合は、あらかじめ16色のパレット画像（PモードPNGや4bit BMP）へ変換してから使用することを推奨します。

また、現在の実装では画像幅は8の倍数である必要があります。


## PC-98向け画像をWindows11で作成するときのポイント

自分で描く時や、AIに画像生成を依頼するときのための覚書です。
※間違っているかもし得ないですが、当たらずとも遠からずだと思います

### 色数

PC-98は4096色中16色表示なので、
* 色は16色以下で描く
* 16色以上のまま描くとPC-98への変換時に色が変わる

ゲーム用画像の場合は、
* 透過色
* メッセージ色（白）
* メッセージボックス色（黒）
を使用するため、実質的に自由に使える色は13色程度になります。

一枚絵であれば16色すべてを自由に使用できます。

### パレット

PC-98は RGB 各4bit（0～15）を使用します。
```
16 × 16 × 16 = 4096色
```
Windowsでは通常 RGB 各8bit（0～255）で扱います。

例えば白色の場合、
```text
Windows
(255,255,255)
↓
PC-98
(15,15,15)
```
となります。

PC-98への変換では、
```text
255 ÷ 17 = 15
```
のようにWindowsのRGB値を17で割ってPC-98の値へ変換する場合が多いため、RGB値は17刻みを意識すると実機との差が少なくなります。
```text
255 → 15
238 → 14
221 → 13
204 → 12
187 → 11
170 → 10
153 →  9
136 →  8
119 →  7
102 →  6
 85 →  5
 68 →  4
 51 →  3
 34 →  2
 17 →  1
  0 →  0
```

例えば、
```text
(170,187,255)
```
は、
```text
(10,11,15)
```
に対応します。

また、PC-98ではRGB各4bitしか使用できないため、
```text
(255,255,255)
(254,255,255)
```
のような近い色は同じ色として扱われます。
Windows上では別の色でも、PC-98へ変換すると同じ色に丸められる場合があります。

### 解像度

PC-98の標準解像度は640×400です。
最初から640×400で描いた方が後で楽です。
Windowsで1280×800などの高解像度で描いてから縮小すると、
* 細い線
* ドット模様
* タイル模様
などが潰れます。

特にPC-98風のタイル床やレンガ模様は縮小で崩れやすいため注意してください。

### PNG保存

PC-98向け画像は、可能であればPNGをインデックスモード（Pモード）で保存します。
RGB/RGBA画像のまま保存すると、変換時に減色処理が行われるため色が変わる場合があります。
インデックスモードで保存しておけば、
* 使用色を確認しやすい
* 意図しない色の混入を防げる
* PC-98向けの16色管理がしやすい
という利点があります。

特に16色で仕上げた画像は、PモードPNGとして保存しておくと扱いやすくなります。
